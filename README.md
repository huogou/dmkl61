# dmkl61

桌宠：六一 / 可乐 / 大米

一款运行在桌面角落的小宠物，透明、置顶、不打扰工作，能跟着鼠标走、偶尔说说话、逗你开心。

## 功能

- **自己会动**：发呆、伸懒腰、打哈欠、摇尾巴，随时在桌面角落闲逛
- **眼神跟着**：鼠标移动时眼神跟着你看，金渐层时还会正视前方
- **多种动作**：单点击猫、双击最小化、右键打开菜单、长按、拖动听话
- **会说话**：可以给它配几句台词，它会随机冒泡
- **开机启动**：登录 Windows 自动在桌面陪你；设置页「显示与交互 → 开机启动」可随时关闭
- **不碍事**：透明窗口、置顶、不占任务栏；空白区点击直接最小化到托盘；按住 Ctrl 可以临时恢复操作

## 下载

前往 [GitHub Releases 页面](https://github.com/huogou/dmkl61/releases) 下载最新版，解压后运行 `dmkl61.exe` 即可，免安装。

## 自定义宠物

在设置页面中，点击「资源」选项，可以查看帧动画生成教程。生成好的帧动画可以使用「视频转 WebP 图片」工具，直接转换成可用的素材。

## 常见问题

**为什么打开是空白的/没有猫？**

第一次运行需要准备默认素材。前往 [GitHub Releases 页面](https://github.com/huogou/dmkl61/releases) 下载 `dmkl61-resources.zip` 压缩包，解压后把 `resources/` 文件夹放到 `dmkl61.exe` 同级目录下，然后重新打开即可。

**怎么让它不挡我点东西？**

右键菜单开启，左键点击猫猫就完全透明了；按住 Ctrl 可以暂时恢复操作。
